\begin{frame}[t]{今天就能开始用的小知识}
在程序设计中，鸭子类型（英语：duck typing）是动态类型的一种风格。在这种风格中，一个对象有效的语义，不是由继承自特定的类或实现特定的接口，而是由"当前方法和属性的集合"决定。这个概念的名字来源于由James Whitcomb Riley提出的鸭子测试，“鸭子测试”可以这样表述：
\begin{block}{鸭子测试}
\begin{itemize}
		\item If it walks like a duck
		\item It quacks like a duck
		\item Then it must be a duck
\end{itemize}
\end{block}
“当看到一只鸟走起来像鸭子、游泳起来像鸭子、叫起来也像鸭子，那么这只鸟就可以被称为鸭子。”	\footnote{\url{https://en.wikipedia.org/wiki/Duck_typing}}
\end{frame}

\end{block}

\begin{frame}[t,fragile]{Monkey Sort}
在计算机科学中，Bogo排序（bogo-sort）是个非常低效率的排序算法，通常用在教学或测试。其原理等同将一堆卡片抛起，落在桌上后检查卡片是否已整齐排列好，若非就再抛一次，又称bozo sort、blort sort或猴子排序。其平均时间复杂度是 $O(n \times n!)$，在最坏情况所需时间是无限。它并非一个稳定的算法\footnote{\url{https://en.wikipedia.org/wiki/Bogosort}}。


\end{frame}

\begin{frame}[t]{什么是函数式}
    函数式编程（functional programming）或称函数程序设计，是一种编程典范，它将电脑运算视为数学上的函数计算，并且避免使用程序状态以及易变对象。函数编程语言最重要的基础是$\lambda$演算（lambda calculus）。而且$\lambda$演算的函数可以接受函数当作输入（引数）和输出（传出值）。

    比起命令式编程，函数式编程更加强调程序执行的结果而非执行的过程，倡导利用若干简单的执行单元让计算结果不断渐进，逐层推导复杂的运算，而不是设计一个复杂的执行过程。
\end{frame}

\begin{frame}[t]{函数式特性}
    \begin{itemize}
        \item First-class and higher-order functions
        \item Pure function
        \item Recursion
        \item Type system
				\item \ldots

            
    \end{itemize}
\end{frame}

\begin{frame}[t]{$\lambda$演算}
    $\lambda$演算（英语：lambda calculus，$\lambda$-calculus）是一套从数学逻辑中发展，以变量绑定和替换的规则，来研究函数如何抽象化定义、函数如何被应用以及递归的形式系统。它由数学家阿隆佐·邱奇在20世纪30年代首次发表。Lambda演算作为一种广泛用途的计算模型，可以清晰地定义什么是一个可计算函数，而任何可计算函数都能以这种形式表达和求值，它能模拟单一磁带图灵机的计算过程；尽管如此，Lambda演算强调的是变换规则的运用，而非实现它们的具体机器。
\end{frame}

\end{frame}

\begin{frame}[t]{Dictionaries}

    \begin{itemize}
        \item 字典类似其他语言中散列表、关联数组，按键值方式组织
        \item 不像列表元组可以用下标随机访问
        \item 任何不可变对象均可作为键（元组亦可，但不能包含可变元素）
        \item 空字典用\{\}构造；非空字典在\{\}内逗号分割的键:值对表示
        \item list(d.keys())返回所有键。如需有序，使用sorted(d.keys())
    \end{itemize}

\end{frame}

\subsection{集合}
\label{ssub:集合}

\begin{frame}[t]{Sets}

    \begin{itemize}
        \item 集合是无序无重复的数据结构
        \item 支持成员测试、添加、删除等操作
        \item 支持交集、并集、差等集合操作
        \item 初始化用\{\}括住的逗号分割元素序列
        \item 空集合用set()，而不是\{\}
        \item 集合推导同样支持
   \end{itemize}

\end{frame}




\begin{frame}[t,fragile]{Sets}
    \scriptsize
\begin{verbatim}
>>> basket = {'apple', 'orange', 'apple', 'pear', 'orange', 'banana'}
>>> print(basket)                      # show that duplicates have been removed
{'orange', 'banana', 'pear', 'apple'}
>>> 'orange' in basket                 # fast membership testing
True
>>> 'crabgrass' in basket
False

>>> # Demonstrate set operations on unique letters from two words
...
>>> a = set('abracadabra')
>>> b = set('alacazam')
>>> a                                  # unique letters in a
{'a', 'r', 'b', 'c', 'd'}
>>> a - b                              # letters in a but not in b
{'r', 'd', 'b'}
>>> a | b                              # letters in a or b or both
{'a', 'c', 'r', 'd', 'b', 'm', 'z', 'l'}
>>> a & b                              # letters in both a and b
{'a', 'c'}
>>> a ^ b                              # letters in a or b but not both
{'r', 'd', 'b', 'm', 'z', 'l'}


\end{verbatim}
\end{frame}
