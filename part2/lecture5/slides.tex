\begin{frame}[t,fragile]{成员变量和实例变量}


\begin{verbatim}


class Dog:

    tricks = []             # mistaken use of a class variable

    def __init__(self, name):
        self.name = name

    def add_trick(self, trick):
        self.tricks.append(trick)

>>> d = Dog('Fido')
>>> e = Dog('Buddy')
>>> d.add_trick('roll over')
>>> e.add_trick('play dead')
>>> d.tricks                # unexpectedly shared by all dogs
['roll over', 'play dead']


\end{verbatim}


\end{frame}

\begin{frame}[t]{实例/类的成员}
	\begin{itemize}
		\item 在\_\_init\_\_中用self.初始化的是实例成员
		\item 在类似C++成员声明处初始化的是类成员（类似静态变量）
		\item 实例成员可以动态添加和删除
		\item 必要时用hasattr判断是否包含某成员

    def foo(self):

\begin{frame}[t]{鸭子类型}
在程序设计中，鸭子类型（英语：duck typing）是动态类型的一种风格。在这种风格中，一个对象有效的语义，不是由继承自特定的类或实现特定的接口，而是由"当前方法和属性的集合"决定。这个概念的名字来源于由James Whitcomb Riley提出的鸭子测试，“鸭子测试”可以这样表述：
\begin{block}{鸭子测试}
\begin{itemize}
		\item If it walks like a duck
		\item It quacks like a duck
		\item Then it must be a duck
\end{itemize}
\end{block}
“当看到一只鸟走起来像鸭子、游泳起来像鸭子、叫起来也像鸭子，那么这只鸟就可以被称为鸭子。”	\footnote{\url{https://en.wikipedia.org/wiki/Duck_typing}}
\end{frame}

\begin{frame}[t,fragile]{多态}
\begin{verbatim}
class A:
    def foo(self):
        print("in A::foo")

class B(A):
    def foo(self):
        print("in B::foo")

class C:
    def foo(self):
        print("not subclass of A/B")

def test_class(a):
    a.foo()

if __name__ == "__main__"
    a = A()
    b = B()
    c = C()
    test_class(a)
    test_class(b)
    test_class(c)
\end{verbatim}
	
\end{frame}

\section{函数式特性} % (fold)
\label{sec:函数式特性}
\begin{frame}[t]{什么是函数式}
    函数式编程（functional programming）或称函数程序设计，是一种编程典范，它将电脑运算视为数学上的函数计算，并且避免使用程序状态以及易变对象。函数编程语言最重要的基础是$\lambda$演算（lambda calculus）。而且$\lambda$演算的函数可以接受函数当作输入（引数）和输出（传出值）。

    比起命令式编程，函数式编程更加强调程序执行的结果而非执行的过程，倡导利用若干简单的执行单元让计算结果不断渐进，逐层推导复杂的运算，而不是设计一个复杂的执行过程。
\end{frame}

\begin{frame}[t]{函数式特性}
    \begin{itemize}
        \item First-class and higher-order functions
        \item Pure function
        \item Recursion
        \item Type system
				\item \ldots

            
    \end{itemize}
\end{frame}

\begin{frame}[t]{$\lambda$演算}
    $\lambda$演算（英语：lambda calculus，$\lambda$-calculus）是一套从数学逻辑中发展，以变量绑定和替换的规则，来研究函数如何抽象化定义、函数如何被应用以及递归的形式系统。它由数学家阿隆佐·邱奇在20世纪30年代首次发表。Lambda演算作为一种广泛用途的计算模型，可以清晰地定义什么是一个可计算函数，而任何可计算函数都能以这种形式表达和求值，它能模拟单一磁带图灵机的计算过程；尽管如此，Lambda演算强调的是变换规则的运用，而非实现它们的具体机器。
\end{frame}

\begin{frame}[t,fragile]{$\lambda$表达式}
\begin{verbatim}

add = lambda x, y: x + y

inc(5)
add(10, 20)

# 注意：Python的lambda表达式不能换行


\end{verbatim}
	
\end{frame}
