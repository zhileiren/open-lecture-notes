\scriptsize

\begin{verbatim}
html_doc = """
<html><head><title>The Dormouse's story</title></head>
<body>

\section{遍历文档树}


\begin{frame}[t,fragile]{遍历文档树}

还拿"爱丽丝梦游仙境"的文档来做例子:

\tiny
\begin{verbatim}

html_doc = """
<html><head><title>The Dormouse's story</title></head>

<p class="title"><b>The Dormouse's story</b></p>

<p class="story">Once upon a time there were three little sisters; and their names were
<a href="http://example.com/elsie" class="sister" id="link1">Elsie</a>,
<a href="http://example.com/lacie" class="sister" id="link2">Lacie</a> and
<a href="http://example.com/tillie" class="sister" id="link3">Tillie</a>;
and they lived at the bottom of a well.</p>

<p class="story">...</p>
"""

from bs4 import BeautifulSoup
soup = BeautifulSoup(html_doc)


\end{verbatim}


\end{frame}


\begin{frame}[t]{遍历文档树}

通过这段例子来演示怎样从文档的一段内容找到另一段内容

\begin{block}
    {遍历方法}
    \begin{itemize}
        \item 使用点号遍历，如doc.body.a代表body下第一个<a>连接
        \item .descendants表示子节点
        \item .next\_element表示下一个节点
        \item .next\_sibling表示下一个兄弟
        \item .name返回标签类型
        \item .get\_text()返回文本
        \item 复数表示生成器
        \item find\_all更好用
        \item select也不错，支持CSS选择器
    \end{itemize}
\end{block}

\end{frame}


\begin{frame}[t,fragile]{遍历文档树}


\begin{verbatim}

soup.head
# <head><title>The Dormouse's story</title></head>

soup.title
# <title>The Dormouse's story</title>


\end{verbatim}


\end{frame}



\begin{frame}[t,fragile]{遍历文档树}

通过点取属性的方式只能获得当前名字的第一个tag:

\begin{verbatim}

soup.a
# <a class="sister" href="http://example.com/elsie" id="link1">Elsie</a>


\end{verbatim}


\end{frame}

\begin{frame}[t,fragile]{遍历文档树}

如果想要得到所有的<a>标签,或是通过名字得到比一个tag更多的内容的时候,就需要用到 Searching the tree 中描述的方法,比如: find\_all()

\begin{verbatim}

soup.find_all('a')
# [<a class="sister" href="http://example.com/elsie" id="link1">Elsie</a>,
#  <a class="sister" href="http://example.com/lacie" id="link2">Lacie</a>,
#  <a class="sister" href="http://example.com/tillie" id="link3">Tillie</a>]


\end{verbatim}


\end{frame}

\begin{frame}[t,fragile]{遍历文档树}

tag的 .contents 属性可以将tag的子节点以列表的方式输出:

\begin{verbatim}

head_tag = soup.head
head_tag
# <head><title>The Dormouse's story</title></head>

head_tag.contents
[<title>The Dormouse's story</title>]

title_tag = head_tag.contents[0]
title_tag
# <title>The Dormouse's story</title>
title_tag.contents
# [u'The Dormouse's story']

\end{verbatim}


\end{frame}

\begin{frame}[t,fragile]{遍历文档树}

BeautifulSoup 对象本身一定会包含子节点,也就是说<html>标签也是 BeautifulSoup 对象的子节点:

\begin{verbatim}

len(soup.contents)
# 1
soup.contents[0].name
# u'html'


\end{verbatim}


\end{frame}

通过tag的 .children 生成器,可以对tag的子节点进行循环:

\begin{verbatim}

for child in title_tag.children:
    print(child)

\end{verbatim}


\end{frame}

继续分析文档树,每个tag或字符串都有父节点:被包含在某个tag中

通过 .parent 属性来获取某个元素的父节点.在例子“爱丽丝”的文档中,<head>标签是<title>标签的父节点:
\end{frame}

\begin{frame}[t,fragile]{遍历文档树}

title_tag = soup.title

\end{frame}

\end{frame}


\begin{frame}[t,fragile]{遍历文档树}

通过元素的 .parents 属性可以递归得到元素的所有父辈节点,下面的例子使用了 .parents 方法遍历了<a>标签到根节点的所有节点.

\begin{verbatim}
link = soup.a

# <a class="sister" href="http://example.com/elsie" id="link1">Elsie</a>
for parent in link.parents:

    else:
        print(parent.name)

# body
# html
# [document]
# None


\end{verbatim}


\end{frame}

\begin{frame}[t]{遍历文档树}

\end{frame}

\end{frame}

\section{搜索文档树}


\begin{frame}[t,fragile]{搜索文档树}

Beautiful Soup定义了很多搜索方法,这里着重介绍2个: find() 和 find\_all() .其它方法的参数和用法类似,请读者举一反三.

使用 find\_all() 类似的方法可以查找到想要查找的文档内容

介绍 find\_all() 方法前,先介绍一下过滤器的类型,这些过滤器贯穿整个搜索的API.过滤器可以被用在tag的name中,节点的属性中,字符串中或他们的混合中.

最简单的过滤器是字符串.在搜索方法中传入一个字符串参数,Beautiful Soup会查找与字符串完整匹配的内容,下面的例子用于查找文档中所有的<b>标签:

\begin{verbatim}

soup.find_all('b')
# [<b>The Dormouse's story</b>]


\end{verbatim}


\end{frame}

\begin{frame}[t,fragile]{搜索文档树}

如果传入正则表达式作为参数,Beautiful Soup会通过正则表达式来匹配内容.下面例子中找出所有以b开头的标签,这表示<body>和<b>标签都应该被找到:

\begin{verbatim}
import re
for tag in soup.find_all(re.compile("^b")):
    print(tag.name)
# body
# b
\end{verbatim}


\end{frame}



\begin{frame}[t,fragile]{搜索文档树}

下面代码找出所有名字中包含”t”的标签:
\begin{verbatim}
for tag in soup.find_all(re.compile("t")):
    print(tag.name)
# html
# title


\end{verbatim}


\end{frame}


\begin{frame}[t,fragile]{搜索文档树}

如果传入列表参数,Beautiful Soup会将与列表中任一元素匹配的内容返回.下面代码找到文档中所有<a>标签和<b>标签:

\begin{verbatim}
soup.find_all(["a", "b"])
# [<b>The Dormouse's story</b>,
#  <a class="sister" href="http://example.com/elsie" id="link1">Elsie</a>,
#  <a class="sister" href="http://example.com/lacie" id="link2">Lacie</a>,
#  <a class="sister" href="http://example.com/tillie" id="link3">Tillie</a>]


\end{verbatim}


\end{frame}


\begin{frame}[t,fragile]{搜索文档树}

True 可以匹配任何值,下面代码查找到所有的tag,但是不会返回字符串节点

\begin{verbatim}
for tag in soup.find_all(True):
    print(tag.name)
# html
# head
# title
# body
# p
# b
# p
# a
# a
# a
# p


\end{verbatim}
\end{frame}

\begin{frame}[t,fragile]{搜索文档树}

find\_all( name , attrs , recursive , text , **kwargs )

find\_all() 方法搜索当前tag的所有tag子节点,并判断是否符合过滤器的条件.这里有几个例子:

\tiny
\begin{verbatim}

soup.find_all("title")
# [<title>The Dormouse's story</title>]

soup.find_all("p", "title")
# [<p class="title"><b>The Dormouse's story</b></p>]

soup.find_all("a")
# [<a class="sister" href="http://example.com/elsie" id="link1">Elsie</a>,
#  <a class="sister" href="http://example.com/lacie" id="link2">Lacie</a>,
#  <a class="sister" href="http://example.com/tillie" id="link3">Tillie</a>]

soup.find_all(id="link2")
# [<a class="sister" href="http://example.com/lacie" id="link2">Lacie</a>]

import re
soup.find(text=re.compile("sisters"))
# u'Once upon a time there were three little sisters; and their names were\n'


\end{verbatim}


\end{frame}



\begin{frame}[t,fragile]{搜索文档树}

name 参数可以查找所有名字为 name 的tag,字符串对象会被自动忽略掉.

\begin{verbatim}

soup.find_all("title")
# [<title>The Dormouse's story</title>]

soup.find_all(id='link2')
# [<a class="sister" href="http://example.com/lacie" id="link2">Lacie</a>]



\end{verbatim}
\end{frame}


\begin{frame}[t,fragile]{搜索文档树}

如果传入 href 参数,Beautiful Soup会搜索每个tag的”href”属性:

\begin{verbatim}

soup.find_all(href=re.compile("elsie"))
# [<a class="sister" href="http://example.com/elsie" id="link1">Elsie</a>]


\end{verbatim}


\end{frame}

\begin{frame}[t,fragile]{搜索文档树}

使用多个指定名字的参数可以同时过滤tag的多个属性:

\begin{verbatim}

soup.find_all(href=re.compile("elsie"), id='link1')
# [<a class="sister" href="http://example.com/elsie" id="link1">three</a>]


\end{verbatim}


\end{frame}

\begin{frame}[t,fragile]{搜索文档树}

可以通过 find\_all() 方法的 attrs 参数定义一个字典参数来搜索包含特殊属性的tag:

\begin{verbatim}

data_soup.find_all(attrs={"data-foo": "value"})
# [<div data-foo="value">foo!</div>]


\end{verbatim}


\end{frame}

\begin{frame}[t,fragile]{搜索文档树}

按照CSS类名搜索tag的功能非常实用,但标识CSS类名的关键字 class 在Python中是保留字,使用 class 做参数会导致语法错误.从Beautiful Soup的4.1.1版本开始,可以通过 class\_ 参数搜索有指定CSS类名的tag:

\scriptsize
\begin{verbatim}

soup.find_all("a", class_="sister")
# [<a class="sister" href="http://example.com/elsie" id="link1">Elsie</a>,
#  <a class="sister" href="http://example.com/lacie" id="link2">Lacie</a>,
#  <a class="sister" href="http://example.com/tillie" id="link3">Tillie</a>]


\end{verbatim}


\end{frame}

\begin{frame}[t,fragile]{搜索文档树}

tag的 class 属性是 多值属性 .按照CSS类名搜索tag时,可以分别搜索tag中的每个CSS类名:
\scriptsize

\begin{verbatim}

css_soup = BeautifulSoup('<p class="body strikeout"></p>')
css_soup.find_all("p", class_="strikeout")
# [<p class="body strikeout"></p>]

css_soup.find_all("p", class_="body")
# [<p class="body strikeout"></p>]


\end{verbatim}


\end{frame}

\begin{frame}[t,fragile]{搜索文档树}

通过 text 参数可以搜搜文档中的字符串内容.与 name 参数的可选值一样, text 参数接受 字符串 , 正则表达式 , 列表, True . 看例子:

\scriptsize
\begin{verbatim}

soup.find_all(text="Elsie")
# [u'Elsie']

soup.find_all(text=["Tillie", "Elsie", "Lacie"])
# [u'Elsie', u'Lacie', u'Tillie']

soup.find_all(text=re.compile("Dormouse"))
[u"The Dormouse's story", u"The Dormouse's story"]

\end{verbatim}

\end{frame}


\begin{frame}[t,fragile]{搜索文档树}

虽然 text 参数用于搜索字符串,还可以与其它参数混合使用来过滤tag.Beautiful Soup会找到 .string 方法与 text 参数值相符的tag.下面代码用来搜索内容里面包含“Elsie”的<a>标签:

\begin{verbatim}

soup.find_all("a", text="Elsie")
# [<a href="http://example.com/elsie" class="sister" id="link1">Elsie</a>]


\end{verbatim}


\end{frame}

\begin{frame}[t]{搜索文档树}

find\_all() 和 find() 只搜索当前节点的所有子节点,孙子节点等. find\_parents() 和 find\_parent() 用来搜索当前节点的父辈节点,搜索方法与普通tag的搜索方法相同,搜索文档搜索文档包含的内容. 我们从一个文档中的一个叶子节点开始:

\end{frame}


\begin{frame}[t,fragile]{搜索文档树}


\begin{verbatim}

a_string = soup.find(text="Lacie")
a_string
# u'Lacie'

a_string.find_parents("a")
# [<a class="sister" href="http://example.com/lacie" id="link2">Lacie</a>]

a_string.find_parent("p")
# <p class="story">Once upon a time there were three little sisters; and their names were
#  <a class="sister" href="http://example.com/elsie" id="link1">Elsie</a>,
#  <a class="sister" href="http://example.com/lacie" id="link2">Lacie</a> and
#  <a class="sister" href="http://example.com/tillie" id="link3">Tillie</a>;
#  and they lived at the bottom of a well.</p>

a_string.find_parents("p", class="title")
# []

\end{verbatim}


\end{frame}

\begin{frame}[t,fragile]{搜索文档树}

Beautiful Soup支持大部分的CSS选择器,在 Tag 或 BeautifulSoup 对象的 .select() 方法中传入字符串参数,即可使用CSS选择器的语法找到tag:

\begin{verbatim}

soup.select("title")
# [<title>The Dormouse's story</title>]

soup.select("p nth-of-type(3)")
# [<p class="story">...</p>]


\end{verbatim}


\end{frame}
