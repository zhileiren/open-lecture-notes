
# 第一部分：开源软件发展  

学生通过本章学习，将对开源软件的定义、发展历史、开源软件许可证制度以及开源技术选型有全面的认识。

## 1. 开源软件的概念和历史

内容包括：开源软件的定义，开源软件的历史与发展，开源软件、自由软件、商用软件的区别于联系

## 2. 开源软件仓库与开源软件生态系统

内容包括：开源软件仓库的定义、分类，典型开源软件仓库介绍、开软件件生态系统、开源软件运营模式。

## 3. 开源软件许可证制度

内容包括：开源软件许可证的概念、特点、典型开源软件许可证介绍、许可证相容性关系，并以GPL为案例进行详细解释分析。

## 4. 开源软件成熟度评估与选型

内容包括：开源软件成熟的评估的目标、评估模型、评估方法，以及典型开源软件仓库的成熟度评估结果分析。

# 第二部分：开源软件仓库数据获取  

讲授开源软件仓库的结构，并以python为案例，讲解如何实现自动化获取开源软件数据，并实现数据的过滤。

## 5. 开源软件仓库结构

内容包括：开源软件仓库的组成部分。以典型开源软件仓库为案例，讲解开源代码、文档、缺陷报告系统结构。

## 6. 基于python的数据获取（1）：python入门

内容包括：python开发环境的搭建，基于ipython/jupyter的交互式环境使用、面向过程的程序开发。

## 7. 基于python的数据获取（2）：python的进阶知识

内容包括：python语言的进阶知识，如面向对象、列表解析（list comprehension）、lambda算子、函数式特性等。

## 8. 基于python的数据获取（3）：requests、scrapy与pyspider

内容包括：基于requests库的数据爬取和基于scrapy、pyspider模板的爬取程序开发。

## 9. 基于python的数据获取（4）：基于beautifulSoup的数据过滤

内容包括：讲解如何使用beautifulSoup库实现对爬取的开源软件数据进行数据抽取和过滤，获得有价值的数据。

# 第三部分：基于开源软件的团队开发

以主流版本控制工具git为案例，讲解如何实现团队开发、测试与管理。

## 10. 版本控制的概念与入门

内容包括：版本控制的概念、git的初步命令，包括初始化、提交、版本变更、分支与归并。

## 11. 基于git的团队协作

内容包括：以github为案例，引导学生分组并创建项目，编写项目wiki，使用issue tracking管理软件缺陷。

## 12. 基于nose的测试自动化

内容包括：以python库nose为案例，讲解测试用例的编写、部署以及自动执行。

## 13. git提交日志分析

内容包括：git提交日志的结构、获取，以及通过解析git日志分析团队开发习惯。

# 第四部分：开源软件数据存储与转换  

在数据获取的基础上，讲解如何根据数据类型，实现结构化数据在关系型数据库的存储，半结构化数据在NoSQL数据库的存储，数据转换以及探索性分析。

## 14. 基于sqlalchemy的结构化数据存储

内容包括：对开源软件仓库数据中的结构化部分，使用关系型数据模型进行建模，并讲解使用sqlalchemy库将数据存储如mysql等关系型数据库。

## 15. 基于pymongodb的半结构化数据存储

内容包括：对开源软件仓库数据中的半结构化部分，使用非关系型数据模型进行建模，并讲解将数据存储如mongodb等非关系型数据库。

## 16. 基于kettle的数据转换

内容包括：关系型数据库与非关系型数据库数据的转换，以kettle开源工具为例，讲解如何将关系型数据库中的数据导入非关系型数据库。

## 17. 基于pandas的开源软件数据探索性分析

内容包括：讲解数据分析包pandas的使用，并结合开源软件数据，讲解如何进行探索性分析。

# 第五部分：开源软件数据应用  

讲解分析结果的呈现，包括图表生成自动化以及web应用的开发。

## 18. 基于matplotlib和ggplot的图表生成自动化

内容包括：结合开源软件数据，讲解如何使用matplotlib和ggplot进行数据可视化展示。

## 19. 基于webpy与django的web应用框架

内容包括：讲解web框架web.py和django的使用，讨论使用python进行web开发的基本流程。

## 20. python web应用案例分析

内容包括：将探索性分析、可视化以及web库。结合案例，分析如何实现完整的开发流程，并讨论如何对工程进行测试。
