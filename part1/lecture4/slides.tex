\subsection{数值}

\begin{frame}[t]{数值}

	\begin{itemize}
		\item Python解释器可以当计算器使
		\item 加减乘除都支持
		\item 括号也能用
		\item 整形类型为int
		\item 有小数点的类型为float
	\end{itemize}

\end{frame}


\begin{frame}[t,fragile]{数值}


\begin{verbatim}


>>> 2 + 2
4
>>> 50 - 5*6
20
>>> (50 - 5*6) / 4
5.0
>>> 8 / 5  # 除法返回浮点数
1.6


\end{verbatim}


\end{frame}




\begin{frame}[t]{数值}

	\begin{itemize}
		\item 除法
	\end{itemize}

Division (/) always returns a float.  To do floor division and
get an integer result (discarding any fractional result) you can use the //
operator; to calculate the remainder you can use \%:

\end{frame}


\begin{frame}[t,fragile]{数值}


\begin{verbatim}


>>> 17 / 3  # classic division returns a float
5.666666666666667
>>>
>>> 17 // 3  # floor division discards the fractional part
5
>>> 17 % 3  # the % operator returns the remainder of the division
2
>>> 5 * 3 + 2  # result * divisor + remainder
17


\end{verbatim}


\end{frame}


\begin{frame}[t]{数值}

With Python, it is possible to use the ** operator to calculate powers [1]:

\end{frame}


\begin{frame}[t,fragile]{数值}


\begin{verbatim}


>>> 5 ** 2  # 5 squared
25
>>> 2 ** 7  # 2 to the power of 7
128


\end{verbatim}


\end{frame}


\begin{frame}[t]{数值}

The equal sign (=) is used to assign a value to a variable. Afterwards, no
result is displayed before the next interactive prompt:

\end{frame}


\begin{frame}[t,fragile]{数值}


\begin{verbatim}


>>> width = 20
>>> height = 5 * 9
>>> width * height
900


\end{verbatim}


\end{frame}


\begin{frame}[t]{数值}

If a variable is not "defined" (assigned a value), trying to use it will
give you an error:

\end{frame}


\begin{frame}[t,fragile]{数值}


\begin{verbatim}


>>> n  # try to access an undefined variable
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'n' is not defined


\end{verbatim}


\end{frame}


\begin{frame}[t]{数值}

There is full support for floating point; operators with mixed type operands
convert the integer operand to floating point:

\end{frame}


\begin{frame}[t,fragile]{数值}


\begin{verbatim}


>>> 4 * 3.75 - 1
14.0


\end{verbatim}


\end{frame}


\begin{frame}[t]{数值}

In interactive mode, the last printed expression is assigned to the variable
\_.  This means that when you are using Python as a desk calculator, it is
somewhat easier to continue calculations, for example:

\end{frame}


\begin{frame}[t,fragile]{数值}


\begin{verbatim}


>>> tax = 12.5 / 100
>>> price = 100.50
>>> price * tax
12.5625
>>> price + _
113.0625
>>> round(_, 2)
113.06


\end{verbatim}


\end{frame}


\begin{frame}[t]{数值}

This variable should be treated as read-only by the user.  Don't explicitly
assign a value to it --- you would create an independent local variable with the
same name masking the built-in variable with its magic behavior.

\end{frame}


\begin{frame}[t]{数值}

In addition to int and float, Python supports other types of
numbers, such as ~decimal.Decimal and ~fractions.Fraction.
Python also has built-in support for complex numbers <typesnumeric>,
and uses the j or J suffix to indicate the imaginary part
(e.g. 3+5j).

\end{frame}
\subsection{字符串}

\begin{frame}[t]{字符串}

Besides numbers, Python can also manipulate strings, which can be expressed
in several ways.  They can be enclosed in single quotes ('...') or
double quotes ("...") with the same result [2].  \textbackslash  can be used
to escape quotes:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> 'spam eggs'  # single quotes
'spam eggs'
>>> 'doesn\'t'  # use \' to escape the single quote...
"doesn't"
>>> "doesn't"  # ...or use double quotes instead
"doesn't"
>>> '"Yes," he said.'
'"Yes," he said.'
>>> "\"Yes,\" he said."
'"Yes," he said.'
>>> '"Isn\'t," she said.'
'"Isn\'t," she said.'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

In the interactive interpreter, the output string is enclosed in quotes and
special characters are escaped with backslashes.  While this might sometimes
look different from the input (the enclosing quotes could change), the two
strings are equivalent.  The string is enclosed in double quotes if
the string contains a single quote and no double quotes, otherwise it is
enclosed in single quotes.  The print function produces a more
readable output, by omitting the enclosing quotes and by printing escaped
and special characters:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> '"Isn\'t," she said.'
'"Isn\'t," she said.'
>>> print('"Isn\'t," she said.')
"Isn't," she said.
>>> s = 'First line.\nSecond line.'  # \n means newline
>>> s  # without print(), \n is included in the output
'First line.\nSecond line.'
>>> print(s)  # with print(), \n produces a new line
First line.
Second line.


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

If you don't want characters prefaced by \textbackslash  to be interpreted as
special characters, you can use raw strings by adding an r before
the first quote:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> print('C:\some\name')  # here \n means newline!
C:\some
ame
>>> print(r'C:\some\name')  # note the r before the quote
C:\some\name


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

String literals can span multiple lines.  One way is using triple-quotes:
"""...""" or '''...'''.  End of lines are automatically
included in the string, but it's possible to prevent this by adding a \textbackslash  at
the end of the line.  The following example:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


print("""\
Usage: thingy [OPTIONS]
     -h                        Display this usage message
     -H hostname               Hostname to connect to
""")


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

produces the following output (note that the initial newline is not included):

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


Usage: thingy [OPTIONS]
     -h                        Display this usage message
     -H hostname               Hostname to connect to


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

Strings can be concatenated (glued together) with the + operator, and
repeated with *:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> # 3 times 'un', followed by 'ium'
>>> 3 * 'un' + 'ium'
'unununium'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

Two or more string literals (i.e. the ones enclosed between quotes) next
to each other are automatically concatenated.

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> 'Py' 'thon'
'Python'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

This only works with two literals though, not with variables or expressions:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> prefix = 'Py'
>>> prefix 'thon'  # can't concatenate a variable and a string literal
  ...
SyntaxError: invalid syntax
>>> ('un' * 3) 'ium'
  ...
SyntaxError: invalid syntax


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

If you want to concatenate variables or a variable and a literal, use +:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> prefix + 'thon'
'Python'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

This feature is particularly useful when you want to break long strings:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> text = ('Put several strings within parentheses '
...         'to have them joined together.')
>>> text
'Put several strings within parentheses to have them joined together.'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

Strings can be indexed (subscripted), with the first character having index 0.
There is no separate character type; a character is simply a string of size
one:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> word = 'Python'
>>> word[0]  # character in position 0
'P'
>>> word[5]  # character in position 5
'n'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

Indices may also be negative numbers, to start counting from the right:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> word[-1]  # last character
'n'
>>> word[-2]  # second-last character
'o'
>>> word[-6]
'P'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

Note that since -0 is the same as 0, negative indices start from -1.

\end{frame}


\begin{frame}[t]{字符串}

In addition to indexing, slicing is also supported.  While indexing is used
to obtain individual characters, slicing allows you to obtain substring:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> word[0:2]  # characters from position 0 (included) to 2 (excluded)
'Py'
>>> word[2:5]  # characters from position 2 (included) to 5 (excluded)
'tho'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

Note how the start is always included, and the end always excluded.  This
makes sure that s[:i] + s[i:] is always equal to s:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> word[:2] + word[2:]
'Python'
>>> word[:4] + word[4:]
'Python'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

Slice indices have useful defaults; an omitted first index defaults to zero, an
omitted second index defaults to the size of the string being sliced.

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> word[:2]   # character from the beginning to position 2 (excluded)
'Py'
>>> word[4:]   # characters from position 4 (included) to the end
'on'
>>> word[-2:]  # characters from the second-last (included) to the end
'on'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

One way to remember how slices work is to think of the indices as pointing
between characters, with the left edge of the first character numbered 0.
Then the right edge of the last character of a string of n characters has
index n, for example:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


 +---+---+---+---+---+---+
 | P | y | t | h | o | n |
 +---+---+---+---+---+---+
 0   1   2   3   4   5   6
-6  -5  -4  -3  -2  -1


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

The first row of numbers gives the position of the indices 0...6 in the string;
the second row gives the corresponding negative indices. The slice from i to
j consists of all characters between the edges labeled i and j,
respectively.

\end{frame}


\begin{frame}[t]{字符串}

For non-negative indices, the length of a slice is the difference of the
indices, if both are within bounds.  For example, the length of word[1:3] is
2.

\end{frame}


\begin{frame}[t]{字符串}

Attempting to use an index that is too large will result in an error:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> word[42]  # the word only has 6 characters
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: string index out of range


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

However, out of range slice indexes are handled gracefully when used for
slicing:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> word[4:42]
'on'
>>> word[42:]
''


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

Python strings cannot be changed --- they are immutable.
Therefore, assigning to an indexed position in the string results in an error:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> word[0] = 'J'
  ...
TypeError: 'str' object does not support item assignment
>>> word[2:] = 'py'
  ...
TypeError: 'str' object does not support item assignment


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

If you need a different string, you should create a new one:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> 'J' + word[1:]
'Jython'
>>> word[:2] + 'py'
'Pypy'


\end{verbatim}


\end{frame}


\begin{frame}[t]{字符串}

The built-in function len returns the length of a string:

\end{frame}


\begin{frame}[t,fragile]{字符串}


\begin{verbatim}


>>> s = 'supercalifragilisticexpialidocious'
>>> len(s)
34


\end{verbatim}


\end{frame}
\subsection{列表}

\begin{frame}[t]{列表}

Python knows a number of compound data types, used to group together other
values.  The most versatile is the list, which can be written as a list of
comma-separated values (items) between square brackets.  Lists might contain
items of different types, but usually the items all have the same type.

\end{frame}


\begin{frame}[t,fragile]{列表}


\begin{verbatim}


>>> squares = [1, 4, 9, 16, 25]
>>> squares
[1, 4, 9, 16, 25]


\end{verbatim}


\end{frame}


\begin{frame}[t]{列表}

Like strings (and all other built-in sequence type), lists can be
indexed and sliced:

\end{frame}


\begin{frame}[t,fragile]{列表}


\begin{verbatim}


>>> squares[0]  # indexing returns the item
1
>>> squares[-1]
25
>>> squares[-3:]  # slicing returns a new list
[9, 16, 25]


\end{verbatim}


\end{frame}


\begin{frame}[t]{列表}

All slice operations return a new list containing the requested elements.  This
means that the following slice returns a new (shallow) copy of the list:

\end{frame}


\begin{frame}[t,fragile]{列表}


\begin{verbatim}


>>> squares[:]
[1, 4, 9, 16, 25]


\end{verbatim}


\end{frame}


\begin{frame}[t]{列表}

Lists also support operations like concatenation:

\end{frame}


\begin{frame}[t,fragile]{列表}


\begin{verbatim}


>>> squares + [36, 49, 64, 81, 100]
[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]


\end{verbatim}


\end{frame}


\begin{frame}[t]{列表}

Unlike strings, which are immutable, lists are a mutable
type, i.e. it is possible to change their content:

\end{frame}


\begin{frame}[t,fragile]{列表}


\begin{verbatim}


>>> cubes = [1, 8, 27, 65, 125]  # something's wrong here
>>> 4 ** 3  # the cube of 4 is 64, not 65!
64
>>> cubes[3] = 64  # replace the wrong value
>>> cubes
[1, 8, 27, 64, 125]


\end{verbatim}


\end{frame}


\begin{frame}[t]{列表}

You can also add new items at the end of the list, by using
the ~list.append method (we will see more about methods later):

\end{frame}


\begin{frame}[t,fragile]{列表}


\begin{verbatim}


>>> cubes.append(216)  # add the cube of 6
>>> cubes.append(7 ** 3)  # and the cube of 7
>>> cubes
[1, 8, 27, 64, 125, 216, 343]


\end{verbatim}


\end{frame}


\begin{frame}[t]{列表}

Assignment to slices is also possible, and this can even change the size of the
list or clear it entirely:

\end{frame}


\begin{frame}[t,fragile]{列表}


\begin{verbatim}


>>> letters = ['a', 'b', 'c', 'd', 'e', 'f', 'g']
>>> letters
['a', 'b', 'c', 'd', 'e', 'f', 'g']
>>> # replace some values
>>> letters[2:5] = ['C', 'D', 'E']
>>> letters
['a', 'b', 'C', 'D', 'E', 'f', 'g']
>>> # now remove them
>>> letters[2:5] = []
>>> letters
['a', 'b', 'f', 'g']
>>> # clear the list by replacing all the elements with an empty list
>>> letters[:] = []
>>> letters
[]


\end{verbatim}


\end{frame}


\begin{frame}[t]{列表}

The built-in function len also applies to lists:

\end{frame}


\begin{frame}[t,fragile]{列表}


\begin{verbatim}


>>> letters = ['a', 'b', 'c', 'd']
>>> len(letters)
4


\end{verbatim}


\end{frame}


\begin{frame}[t]{列表}

It is possible to nest lists (create lists containing other lists), for
example:

\end{frame}


\begin{frame}[t,fragile]{列表}


\begin{verbatim}


>>> a = ['a', 'b', 'c']
>>> n = [1, 2, 3]
>>> x = [a, n]
>>> x
[['a', 'b', 'c'], [1, 2, 3]]
>>> x[0]
['a', 'b', 'c']
>>> x[0][1]
'b'


\end{verbatim}


\end{frame}


\begin{frame}[t]{First Steps Towards Programming}

Of course, we can use Python for more complicated tasks than adding two and two
together.  For instance, we can write an initial sub-sequence of the Fibonacci
series as follows:

\end{frame}


\begin{frame}[t,fragile]{First Steps Towards Programming}


\begin{verbatim}


>>> # Fibonacci series:
... # the sum of two elements defines the next
... a, b = 0, 1
>>> while b < 10:
...     print(b)
...     a, b = b, a+b
...
1
1
2
3
5
8


\end{verbatim}


\end{frame}


\begin{frame}[t]{First Steps Towards Programming}

This example introduces several new features.

\end{frame}


\begin{frame}[t]{First Steps Towards Programming}

The first line contains a multiple assignment: the variables a and b
simultaneously get the new values 0 and 1.  On the last line this is used again,
demonstrating that the expressions on the right-hand side are all evaluated
first before any of the assignments take place.  The right-hand side expressions
are evaluated  from the left to the right.

\end{frame}


\begin{frame}[t]{First Steps Towards Programming}

The while loop executes as long as the condition (here: b < 10)
remains true.  In Python, like in C, any non-zero integer value is true; zero is
false.  The condition may also be a string or list value, in fact any sequence;
anything with a non-zero length is true, empty sequences are false.  The test
used in the example is a simple comparison.  The standard comparison operators
are written the same as in C: < (less than), > (greater than), ==
(equal to), <= (less than or equal to), >= (greater than or equal to)
and != (not equal to).

\end{frame}


\begin{frame}[t]{First Steps Towards Programming}

The body of the loop is indented: indentation is Python's way of grouping
statements.  At the interactive prompt, you have to type a tab or space(s) for
each indented line.  In practice you will prepare more complicated input
for Python with a text editor; all decent text editors have an auto-indent
facility.  When a compound statement is entered interactively, it must be
followed by a blank line to indicate completion (since the parser cannot
guess when you have typed the last line).  Note that each line within a basic
block must be indented by the same amount.

\end{frame}

import turtle

def tree(length,n):
    """ paints a branch of a tree """
    if length < (length/n):
        return                    # 边界条件
    turtle.forward(length)        # 主干
    turtle.left(45)               # 左转分叉 
    tree(length * 0.5,length/n)   # 左子树
    turtle.right(90)              # 右转分叉
    tree(length * 0.5,length/n)   # 右子树
    turtle.left(45)               # 转回
    turtle.backward(length)       # 回到起点
    return                        # 返回
\end{verbatim}
